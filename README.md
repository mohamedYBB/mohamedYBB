### Data scientist, machine learning and generative AI

I build predictive models on large administrative datasets, and production tools that combine statistics with LLMs. My background is in econometrics, which made me careful about evaluation: leakage, calibration and explainability.

Case studies:

- [Predicting long-term unemployment](https://github.com/mohamedYBB/long-term-unemployment-prediction): LightGBM on 15M+ records, a target leak found and removed, calibration, SHAP, survival analysis and forecasting.
- [Automated labour market reports with an LLM](https://github.com/mohamedYBB/automated-labour-market-reports): notes for every group and territory in one run, with an LLM that writes the commentary around figures computed in code.

Stack: Python, SQL, SAS, scikit-learn, LightGBM, XGBoost, SHAP, lifelines, Prophet, Plotly, Streamlit, LLM APIs.
